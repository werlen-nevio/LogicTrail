# Security Policy

## Reporting a vulnerability

Please report security issues privately, not as a public issue or pull request.

Use [Report a vulnerability](https://github.com/werlen-nevio/LogicTrail/security/advisories/new)
in the repository's Security tab. Include what is affected (the CLI, the library API, the viewer or
the Claude Code plugin), the version, steps to reproduce and the impact you expect.

You will get a reply within a week. Once the issue is confirmed, a fix is released and the advisory
is published with credit to you, unless you prefer to stay anonymous.

## Supported versions

LogicTrail is in `0.x`. Security fixes go into the latest release only, so please upgrade before
reporting.
